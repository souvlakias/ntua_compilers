# PCL Language Support

VS Code language support for **PCL**

## Features

### Syntax highlighting for `.pcl` files
- Block comments: `(* ... *)`
- Strings and character literals with escapes (e.g. `"\n"`, `'\''`)
- Integers + reals with exponent notation (e.g. `42`, `4.2e1`)
- Keyword/operator highlighting
- Function-call highlighting for identifiers followed by `(` (e.g. `readInteger(`)

## Development/Installation

### Prerequisites
- `npm` and `node` installed

### Run locally (development)

- Open this folder in VS Code and press `F5` to launch an **Extension Development Host**.

### Install from a `.vsix`

1. Package the extension:
	- `npm i -g @vscode/vsce`
	- `vsce package` 
  	  - Then click `y` to skip warnings
2. Install the generated `.vsix`:
	- VS Code: Extensions → `...` → **Install from VSIX...**
	- or CLI: `code --install-extension ./pcl-language-support-<version>.vsix`


## Notes
The initial template was generated by [yo code](https://www.npmjs.com/package/generator-code?ref=trap.jp) with the **New Language Support** template and still contains some files from that. The actual language support is implemented in:
- `syntaxes/pcl.tmLanguage.json` for syntax highlighting
- `language-configuration.json` for comment toggling and auto-closing pairs
